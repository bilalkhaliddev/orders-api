# Devlog — Orders & Integrations API

Written in English, every working day, in 10 minutes or less. This is English practice, a memory aid, and the evidence Claude reads at each review. Newest entry at the top.

## How to write an entry

Three lines, every day:

- **Did:** what you actually built or studied (be specific: "added Form Request for POST /orders", not "worked on API").
- **Learned:** one thing you understand now that you did not this morning.
- **Blocked:** what stopped you or what you are unsure about — or "nothing".

Before starting a Build task, add one line: **Clarifying question:** the question you would ask a team lead before starting. (Interviewers test this habit on purpose.)

Every Saturday, add a **Week summary** (5–8 lines): what shipped, checkpoint status, what to carry over, link to the 5-minute demo recording.

Rules: plain English, short sentences, no copying from docs. Mistakes are fine — fluency comes from writing daily, not from writing perfectly.
