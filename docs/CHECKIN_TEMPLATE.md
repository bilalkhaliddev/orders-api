# Weekly check-in template

Copy this block into the "Laravel Roadmap" project every Saturday as a new message titled `Week N review`. Keep it honest — "not done" is useful information; "pass" that is not true wastes a review.

```
Week: N
Repo: https://github.com/<user>/orders-api
Branch / tag: main (or the PR link)

Done this week:
- ...
- ...

Checkpoint self-assessment (copy the items from docs/PROGRESS.md for this week):
- <item> → pass / not sure / not done
- <item> → pass / not sure / not done

Blockers / questions:
- ...

Hours spent: X / 12
Demo recording: <link or "recorded locally">

Devlog (last 5 entries): pasted below, or "see DEVLOG.md in repo"
```

## Monday message

```
Week N start
```
That is all. Claude replies with the week's brief (reading order, common mistakes, first Build step, what the Checkpoint will test).

## Mid-week questions

Paste the exact error or the snippet (not a description of it), say what you expected and what you tried. One question per message.
