# Orders API

1. What is This: This is a Laravel Backend Project for Orders Integration Api which I'm building as a 26-week learning capstone.

2. Feature: Authentication & Roles, Products & Orders Management, Stripe Payments, WooCommerce Sync, Background Jobs & Queues.

3. Quality/Tests: Every single feature must have its test which will run on every pull request before deploying/publishing.

4. Deployment: This project will run in Docker and will be deployed on one real server (VPS).

5. Why This project is being built: I have 5+ years of experience in PHP/WordPress/WooCommerce and now I'm learning modern Laravel backend engineering. And this project is the practical part of this learning roadmap.

6. What this repo represents: My every week's progress - commits, devlog and decisions.

7. Status: Week 0 - Setup (October 2026).
